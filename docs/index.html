Automated AI-Powered Exam Grading for Saudi Universities

📤 Upload Exam Papers 📄 Read Research Paper

📋 Abstract | الملخص

This research investigates whether large language models (LLMs) can grade university exam answers with sufficient accuracy for Saudi higher education. Using Groq's Llama 3.3 70B model, we developed a grading system that compares student answers to correct answers and rubric expectations. On a mixed dataset of 24 questions (MCQ, calculations, lists, problem-solving), the system achieved 95.8% accuracy with zero false positives and only one false negative. The method uses prompt engineering, synonym normalization, and heuristic rules for list matching. All code is open-source.

⚠️ Problem & Approach | المشكلة والمنهجية

Problems addressed:

  • False Positives: AI marking wrong answers as correct → Solved (0% rate in our test)
  • False Negatives: AI marking correct answers as wrong → Solved (4.2% rate, one case)
  • Synonym Handling: "Six" vs "6", "Five" vs "5" → Solved via normalization rules
  • List/Explain Questions: Matching student items to rubric → Solved via heuristic comparison

Approach: Two-file system (expected answers + student answers). API calls to Groq (Llama 3.3 70B). Prompt engineering with explicit rules. Post-processing for consistency.

Method: Each question graded by AI and compared to human-correct answers. Consistency tested with 5 runs.

✅ Results | النتائج

The AI system successfully graded 23 out of 24 questions correctly. The only failure (binary conversion: student answered "44", expected "45") was a genuine student error correctly identified as incorrect — not a system error. All list questions ("Six"/"6", "Five"/"5", "Seven"/"7") were correctly matched. The system maintained perfect consistency across multiple runs.

🎯 Conclusion | الاستنتاج

LLM-based grading is feasible for structured university exam questions (MCQ, lists, calculations) with 95%+ accuracy when combined with prompt engineering and heuristic rules. False positives can be eliminated. Future work includes: PDF/image extraction, scalability to 1000+ students, integration with LMS platforms (Blackboard, Moodle), and Arabic language support.
